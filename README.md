
# FUTURE_DS_02 – Customer Retention & Churn Analysis

## 📌 Project Overview

This project analyzes customer retention and churn patterns for a subscription-based business using Power BI.

The analysis focuses on identifying churn trends, understanding customer segments associated with churn, and providing actionable insights to support customer retention.

## 🎯 Objectives

- Analyze customer churn patterns
- Measure customer retention and churn rates
- Identify customer segments with higher churn
- Analyze churn across contract types, tenure, internet services, and payment methods
- Provide actionable recommendations for improving customer retention

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV Dataset

## 📊 Key Performance Indicators

| KPI | Value |
|---|---:|
| Total Customers | 7,043 |
| Churned Customers | 1,869 |
| Churn Rate | 26.5% |
| Retention Rate | 73.5% |
| Average Monthly Charges | 64.76 |

## 📈 Dashboard Analysis

The dashboard analyzes:

- Churned Customers by Contract Type
- Churned Customers by Customer Tenure
- Churn Rate by Contract Type
- Churn Rate by Internet Service
- Churned Customers by Internet Service
- Churned Customers by Payment Method

## 🔍 Key Insights

- The overall customer churn rate is approximately 26.5%.
- Customers with shorter tenure show a notable concentration of churn.
- Contract type is associated with differences in churn levels.
- Internet service type shows differences in customer churn.
- Payment methods show different levels of churned customers.

## 💡 Recommendations

- Focus retention efforts on customers during their early tenure.
- Encourage customers to move toward longer-term contract options where appropriate.
- Monitor customer segments with higher churn rates.
- Review payment and service experiences for segments showing higher churn.
- Use regular churn monitoring to identify customers who may need retention support.
